# عطر و ردا | پریمیم پرفیومز، خالص عطر اور ٹوپیاں (Itr & Rida Luxury Store)

ایک جدید، تیز رفتار اور خوبصورت ای کامرس ویب سائٹ برائے پرفیومز، خالص عطر اور دستکاری ٹوپیاں۔
تیار کردہ برائے پاکستان: کیش آن ڈیلیوری، ایزی پیسہ، جاز کیش، واٹس ایپ آرڈر اور لائیو رائیڈر ٹریکنگ۔

---

## 🚀 گٹ ہب پر اپلوڈ اور لائیو (Online) کرنے کا آسان طریقہ:

### 1. اپنے کمپیوٹر سے گٹ ہب پر کوڈ بھیجنا (Push to GitHub):
اپنے کمپیوٹر یا ٹرمینل میں یہ کمانڈز چلائیں:

```bash
# 1. گٹ شروع کریں
git init

# 2. تمام فائلیں شامل کریں
git add .

# 3. محفوظ کریں (Commit)
git commit -m "عطر و ردا اسٹور کا مکمل کوڈ"

# 4. مین برانچ بنائیں
git branch -M main

# 5. اپنے گٹ ہب ریپوزٹری کا لنک جوڑیں (اپنا یوزر نیم اور ریپو کا نام لکھیں)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# 6. گٹ ہب پر اپلوڈ کر دیں
git push -u origin main
```

---

### 2. گٹ ہب پیجز (GitHub Pages) پر بالکل مفت لائیو کرنا:
اس پروجیکٹ میں `.github/workflows/deploy.yml` پہلے سے شامل کر دی گئی ہے۔ جب آپ گٹ ہب پر کوڈ پش کریں گے:

1. اپنے گٹ ہب ریپوزٹری کے صفحے پر جائیں۔
2. اوپر **Settings** پر کلک کریں۔
3. بائیں جانب مینو میں **Pages** پر کلک کریں۔
4. **Build and deployment** کے تحت **Source** میں **GitHub Actions** منتخب کریں۔
5. بس! چند سیکنڈ میں آپ کی ویب سائٹ اس طرح کے مفت لنک پر لائیو ہو جائے گی:
   `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`

---

### 3. ورسل (Vercel) یا نیٹلی فائی (Netlify) پر 1 کلک میں لائیو کرنا (متبادل طریقہ):
اگر آپ مزید تیز رفتار اور کسٹم ڈومین (جیسے `www.itrandrida.pk`) لگانا چاہتے ہیں:
1. [Vercel.com](https://vercel.com) پر جائیں اور اپنے گٹ ہب اکاؤنٹ سے لاگ ان کریں۔
2. **Add New Project** پر کلک کریں اور اپنی ریپوزٹری منتخب کریں۔
3. **Deploy** کا بٹن دبائیں۔ 30 سیکنڈ میں ویب سائٹ لائیو ہو جائے گی!

---

### 4. اپنے کمپیوٹر پر لوکل چلانا (Run Locally):
```bash
# پیکجز انسٹال کریں
npm install

# ڈویلپمنٹ سرور چلائیں (http://localhost:3000 پر کھلے گا)
npm run dev

# پروڈکشن بلڈ تیار کریں
npm run build
```

## 🌟 اہم فیچرز (Key Features):
- **60 پروڈکٹس کا وسیع کیٹلاگ:**
  - 20 فرانسیسی و مشرقی پرفیومز
  - 20 خالص، الکحل سے پاک سنّت عطر
  - 12 دستکاری عمانی، ترک اور افغان ٹوپیاں
  - 8 شاہی گفٹ پریزنٹیشن بنڈل ڈیلز
- **مکمل فریگرنس نوٹس پیرامڈ (Fragrance Notes Pyramid):** Top, Heart, اور Base نوٹس، پھیلاؤ (Sillage) اور پائیداری (Longevity) تفصیلات۔
- **مقامی ادائیگیاں:** کیش آن ڈیلیوری (COD)، ایزی پیسہ (Easypaisa)، جاز کیش (JazzCash)۔
- **واٹس ایپ ڈائریکٹ آرڈر:** ایک کلک پر خودکار اردو آرڈر میسج کی تیاری۔
- **رائیڈر اسائنمنٹ اور لائیو اسٹیٹس ٹریکنگ:** رائیڈر کا نام، فون نمبر، گاڑی نمبر اور وقتِ ترسیل۔
- **بائی لنگوئل:** اردو اور انگلش دونوں زبانوں میں ہموار سپورٹ۔
